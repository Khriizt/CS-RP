# Publicación de extensiones CloudStream

Esta carpeta contiene los artefactos que deben publicarse en la raíz de la rama
`builds` del repositorio `Khriizt/CS-RP`.

La URL que se agrega en CloudStream es:

`https://raw.githubusercontent.com/Khriizt/CS-RP/builds/repo.json`

`repo.json` apunta a `plugins.json`, y este último contiene el catálogo y las
sumas SHA-256 de cada paquete `.cs3`.
